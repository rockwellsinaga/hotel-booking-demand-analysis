# Data access

The raw CSV is not redistributed in this repository. Download `hotel_bookings.csv` from the public Kaggle source linked in the main README, or export the `hotel_bookings` tab from the attributed Google Sheet.

Expected fields used by the analysis:

`hotel`, `is_canceled`, `lead_time`, `arrival_date_year`, `customer_type`, `distribution_channel`, `is_repeated_guest`
